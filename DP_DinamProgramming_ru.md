# Динамическое программирование

## Prompt:
_Кратко и точно расскажи о динамическом программировании. Приведи примеры на C#. Расскажи области применения_

**Динамическое программирование (ДП)** — это метод оптимизации, при котором задача разбивается на подзадачи, и результаты этих подзадач **сохраняются** (мемоизируются), чтобы не вычислять их повторно.

---
### NB!
### 🔹 **Ключевые идеи:**

* **Разбиение на подзадачи**
* **Повторяющиеся подзадачи**
* **Оптимальное подструктурирование**
* **Кэширование результатов**

### 🔹 **Пример 1: Числа Фибоначчи (с мемоизацией)**
Формула такая "Fn = Fn–2 + Fn–1, где F0=0, F1=1, а n — больше или равно 2 и является целым числом."

```csharp
class Program
{
    static Dictionary<int, long> memo = new Dictionary<int, long>(); // Словарь для хранения уже вычисленных чисел

    static long Fib(int n)
    {
        if (n <= 1) return n;             // Базовый случай: F(0)=0, F(1)=1
        if (memo.ContainsKey(n))          // Если уже считали F(n), вернём из словаря
            return memo[n];

        memo[n] = Fib(n - 1) + Fib(n - 2); // Считаем F(n) = F(n-1) + F(n-2) и сохраняем
        return memo[n];
    }

    static void Main()
    {
        Console.WriteLine(Fib(50)); // Быстро, благодаря кэшированию
    }
}
```

### 🔹 **Пример 2: Задача о рюкзаке (0/1 Knapsack)**
Задача: Есть предметы с весами и ценами. Надо выбрать, какие положить в рюкзак с ограничением по весу, чтобы суммарная ценность была максимальна.

```csharp
class Knapsack
{
	public static int Solve(int[] weights, int[] values, int capacity)
	{
	    int n = weights.Length;
	    int[,] dp = new int[n + 1, capacity + 1]; // Таблица: dp[i,w] = макс. ценность при первых i предметах и весе w

	    for (int i = 1; i <= n; i++)                 // Перебираем предметы
	    {
	        for (int w = 0; w <= capacity; w++)      // Перебираем возможный вес
	        {
	            if (weights[i - 1] <= w)             // Если предмет помещается
	                dp[i, w] = Math.Max(
	                    dp[i - 1, w],                // Не брать предмет
	                    dp[i - 1, w - weights[i - 1]] + values[i - 1] // Взять предмет
	                );
	            else
	                dp[i, w] = dp[i - 1, w];         // Если не помещается — не берём
	        }
	    }

	    return dp[n, capacity]; // Ответ — максимальная ценность при всех предметах и полном весе
	}
}
```

## 🔹 Пример 3: **Размен монет**

**Задача:** Даны монеты номиналов `[1, 3, 4]`. Надо найти **минимальное количество монет**, чтобы получить сумму `n`.

```csharp
public static int MinCoins(int[] coins, int amount)
{
    int[] dp = new int[amount + 1];
    Array.Fill(dp, int.MaxValue);
    dp[0] = 0; // 0 монет нужно, чтобы набрать сумму 0

    for (int i = 1; i <= amount; i++)              // Для каждой суммы от 1 до amount
    {
        foreach (int coin in coins)               // Пробуем каждую монету
        {
            if (i >= coin && dp[i - coin] != int.MaxValue)
                dp[i] = Math.Min(dp[i], dp[i - coin] + 1);
        }
    }

    return dp[amount] == int.MaxValue ? -1 : dp[amount]; // -1 если сумму не собрать
}
```

## 🔹 Пример 4: **Поиск кратчайших путей (Floyd–Warshall)**

**Задача:** Дан граф в виде матрицы смежности. Найти кратчайшие пути между всеми парами вершин.

```csharp
public static void FloydWarshall(int[,] graph)
{
    int n = graph.GetLength(0);
    int[,] dist = (int[,])graph.Clone();

    for (int k = 0; k < n; k++)                  // Промежуточная вершина
    {
        for (int i = 0; i < n; i++)              // Стартовая вершина
        {
            for (int j = 0; j < n; j++)          // Конечная вершина
            {
                if (dist[i, k] + dist[k, j] < dist[i, j])
                    dist[i, j] = dist[i, k] + dist[k, j]; // Улучшаем путь
            }
        }
    }

    // dist[i,j] — кратчайшее расстояние от i до j
}
```

> Входной `graph[i, j] = ∞`, если пути нет, иначе вес ребра.

## 🔹 Пример 5: **Редакционное расстояние (Levenshtein distance)**

**Задача:** Сколько операций (вставка, удаление, замена) нужно, чтобы превратить строку A в B?

```csharp
public static int EditDistance(string a, string b)
{
    int m = a.Length, n = b.Length;
    int[,] dp = new int[m + 1, n + 1];

    for (int i = 0; i <= m; i++) dp[i, 0] = i;    // Удаления
    for (int j = 0; j <= n; j++) dp[0, j] = j;    // Вставки

    for (int i = 1; i <= m; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            if (a[i - 1] == b[j - 1])
                dp[i, j] = dp[i - 1, j - 1]; // Буквы равны — ничего не делаем
            else
                dp[i, j] = 1 + Math.Min(dp[i - 1, j],        // Удаление
                                       Math.Min(dp[i, j - 1], // Вставка
                                                dp[i - 1, j - 1])); // Замена
        }
    }

    return dp[m, n]; // Минимальное количество операций
}
```

## 🔹 Пример 6: **Наибольшая общая подпоследовательность (LCS)**

**Задача:** Найти длину самой длинной последовательности, которая есть и в строке A, и в B (не обязательно подряд).

```csharp
public static int LCS(string a, string b)
{
    int m = a.Length, n = b.Length;
    int[,] dp = new int[m + 1, n + 1];

    for (int i = 1; i <= m; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            if (a[i - 1] == b[j - 1])
                dp[i, j] = dp[i - 1, j - 1] + 1; // Буквы совпали — увеличиваем
            else
                dp[i, j] = Math.Max(dp[i - 1, j], dp[i, j - 1]); // Берём максимум
        }
    }

    return dp[m, n];
}
```
