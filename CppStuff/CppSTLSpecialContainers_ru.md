# Специальные контейнеры STL `bitset` & `tuple`.

## Prompt:

### **`std::bitset` в C++**

#### **📌 Когда использовать?**
- Когда нужна **фиксированная-size битовая маска** (размер известен на этапе компиляции).  
- Для **эффективного хранения флагов/состояний** (например, права доступа, статусы).  
- Для **быстрых битовых операций** (логические AND/OR/XOR, сдвиги).  

#### **⚡ Сложность операций**
- **Доступ к биту (`[]`, `.test()`, `.set()`, `.reset()`)** → `O(1)`  
- **Битовые операции (`&`, `|`, `^`, `~`, `<<`, `>>`)** → `O(N)` (но очень быстро, так как обрабатывается машинными инструкциями)  
- **Подсчёт битов (`.count()`)** → `O(N)` (но часто оптимизируется через `POPCNT` на CPU)  
- **Преобразование в строку (`.to_string()`)** → `O(N)`  

#### **Пример:**
```cpp
#include <bitset>
#include <iostream>

int main() {
    std::bitset<8> bits("11001100"); // 8 бит
    bits.set(0);    // Установить бит 0 в 1 (O(1))
    bits.flip(3);   // Инвертировать бит 3 (O(1))
    std::cout << bits << "\n"; // "11011101"
    std::cout << bits.count() << "\n"; // 6 (O(N), но быстро)
    return 0;
}
```

#### **Плюсы:**
✅ **Быстрее `vector<bool>`** (работает напрямую с битами).  
✅ **Фиксированный размер → нет аллокаций**.  
✅ **Поддержка всех битовых операций**.  

#### **Минусы:**
❌ **Размер должен быть известен на этапе компиляции**.  
❌ **Нет динамического изменения размера** (используйте `vector<bool>` или `boost::dynamic_bitset`).  

#### **Альтернативы:**
- `vector<bool>` (если нужен динамический размер).  
- `boost::dynamic_bitset` (аналог с изменяемым размером).

### **`std::tuple` в C++**

#### **📌 Когда использовать?**
- Когда нужно **хранить гетерогенные данные** (разные типы) в одной структуре.  
- Для **возврата нескольких значений из функции** без создания отдельного класса/структуры.  
- Для **работы с шаблонами и обобщённым кодом** (например, метапрограммирование).  

#### **⚡ Сложность операций**
- **Создание (`std::make_tuple`, конструктор)** → `O(1)` (но зависит от типов)  
- **Доступ к элементам (`std::get<N>(tuple)`, `std::get<T>(tuple)`)** → `O(1)` (компилятор вычисляет смещение)  
- **Копирование/присваивание** → `O(N)` (где `N` – количество элементов, зависит от их типов)  
- **Сравнение (`==`, `<`, `>` и т.д.)** → `O(N)` (поэлементное сравнение)  

#### **Пример:**
```cpp
#include <tuple>
#include <string>
#include <iostream>

int main() {
    // Создание tuple (int, string, double)
    auto person = std::make_tuple(25, "Alice", 170.5);

    // Доступ к элементам (O(1))
    std::cout << "Age: " << std::get<0>(person) << "\n";       // 25
    std::cout << "Name: " << std::get<1>(person) << "\n";      // "Alice"
    std::cout << "Height: " << std::get<2>(person) << "\n";    // 170.5

    // C++17: Structured Bindings (удобный доступ)
    auto [age, name, height] = person;
    std::cout << name << " is " << age << " years old.\n";

    return 0;
}
```
