# Стили форматирования C++ файлов

## Prompt:
_Подготовь простой фрагмент кода на с++ который включает в себя все конструкции языка, что-бы была возможность подготовить правила форматирования исходного кода._
Вот простой фрагмент кода на C++, который включает основные конструкции языка и может быть использован для настройки правил форматирования:

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <memory>
#include <algorithm>
#include <cmath>

// Макросы
#define PI 3.14159
#define SQUARE(x) ((x) * (x))

// Перечисления
enum class Color { RED, GREEN, BLUE };

// Структуры
struct Point {
    int x;
    int y;
};

// Класс с наследованием
class Shape {
public:
    Shape(Color c) : color(c) {}
    virtual ~Shape() = default;
    virtual double area() const = 0;

protected:
    Color color;
};

class Circle : public Shape {
public:
    Circle(double r, Color c) : Shape(c), radius(r) {}

    double area() const override {
        return PI * SQUARE(radius);
    }

private:
    double radius;
};

// Шаблонная функция
template <typename T>
T maxValue(const T& a, const T& b) {
    return (a > b) ? a : b;
}

// Пространства имен
namespace MathUtils {
    double distance(const Point& a, const Point& b) {
        return std::sqrt(SQUARE(a.x - b.x) + SQUARE(a.y - b.y));
    }
}

// Основная функция
int main(int argc, char* argv[]) {
    // Переменные и константы
    const int size = 10;
    auto name = std::string("Example");

    // Условные операторы
    if (argc > 1) {
        std::cout << "Arguments provided: " << argc - 1 << std::endl;
    } else {
        std::cout << "No arguments provided" << std::endl;
    }

    // Циклы
    for (int i = 0; i < size; ++i) {
        std::cout << i << " ";
    }
    std::cout << std::endl;

    int j = 0;
    while (j < size) {
        std::cout << j << " ";
        ++j;
    }
    std::cout << std::endl;

    // Контейнеры STL
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    std::for_each(numbers.begin(), numbers.end(), [](int n) {
        std::cout << n << " ";
    });
    std::cout << std::endl;

    // Умные указатели
    auto circle = std::make_unique<Circle>(5.0, Color::RED);
    std::cout << "Circle area: " << circle->area() << std::endl;

    // Обработка исключений
    try {
        if (size == 0) {
            throw std::runtime_error("Size cannot be zero");
        }
        std::cout << "100 / size = " << 100 / size << std::endl;
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << std::endl;
    }

    // Использование шаблонной функции
    std::cout << "Max value: " << maxValue(5, 10) << std::endl;

    // Использование пространства имен
    Point a{1, 2}, b{4, 6};
    std::cout << "Distance: " << MathUtils::distance(a, b) << std::endl;

    return 0;
}
```

Этот код включает:
1. Директивы препроцессора и макросы
2. Пространства имен
3. Перечисления
4. Структуры и классы
5. Наследование и виртуальные функции
6. Шаблонные функции
7. Основные типы данных
8. Условные операторы
9. Циклы (for, while)
10. Контейнеры STL и алгоритмы
11. Умные указатели
12. Обработку исключений
13. Лямбда-функции
14. Основную функцию с параметрами

Этот фрагмент кода можно использовать для настройки правил форматирования в различных инструментах, таких как clang-format, а также для проверки стиля кодирования.

В вашем примере кода используется стиль форматирования, близкий к **LLVM** или **Google C++ Style**, но с некоторыми элементами **GNU Style**. Давайте разберём основные стили форматирования C++ и их особенности:

---

### 1. **LLVM Style** (используется в вашем примере)
```cpp
// Особенности:
int main(int argc, char* argv[]) {  // Открывающая скобка на той же строке
    if (condition) {                 // Открывающая скобка на той же строке
        // код
    } else {                         // else на той же строке
        // код
    }
}
```
- Открывающие фигурные скобки на той же строке.
- Отступы в 2 пробела.
- Пробелы вокруг операторов.
- Имена типов и функций в camelCase или snake_case.

---

### 2. **Google C++ Style**
```cpp
// Особенности:
int main(int argc, char* argv[]) {  // Как в LLVM, но с некоторыми отличиями
    if (condition) {  // Открывающая скобка на той же строке
        // код
    } else {  // else на той же строке
        // код
    }
}
```
- Похож на LLVM, но с более строгими правилами для именования (например, имена переменных в snake_case).
- Запрет на некоторые конструкции (например, исключения в некоторых случаях).
- Более строгие правила для комментариев и документации.

---

### 3. **GNU Style**
```cpp
// Особенности:
int main (int argc, char *argv[])
{  // Открывающая скобка на новой строке
  if (condition)
    {  // Открывающая скобка на новой строке с отступом
      // код
    }
  else
    {  // else на новой строке
      // код
    }
}
```
- Открывающие скобки на новой строке.
- Отступы в 2 пробела.
- Пробелы вокруг операторов и после запятых.

---

### 4. **K&R Style** (Kernighan & Ritchie)
```cpp
// Особенности:
int main(int argc, char *argv[]) {  // Открывающая скобка на той же строке
    if (condition) {  // Открывающая скобка на той же строке
        // код
    } else {  // else на той же строке
        // код
    }
}
```
- Классический стиль, используемый в книге "The C Programming Language".
- Открывающие скобки на той же строке.
- Минимальные отступы (обычно 4 пробела или табуляция).

---

### 5. **Allman Style** (BSD Style)
```cpp
// Особенности:
int main(int argc, char *argv[])
{  // Открывающая скобка на новой строке
    if (condition)
    {  // Открывающая скобка на новой строке
        // код
    }
    else
    {  // else на новой строке
        // код
    }
}
```
- Все фигурные скобки на новых строках.
- Отступы в 4 пробела или табуляция.
- Часто используется в проектах BSD.

---

### 6. **Whitespace Style**
```cpp
// Особенности:
int main( int argc, char* argv[] )
{  // Открывающая скобка на новой строке
    if ( condition )  // Много пробелов вокруг операторов
    {  // Открывающая скобка на новой строке
        // код
    }
    else
    {
        // код
    }
}
```
- Много пробелов вокруг операторов и после запятых.
- Открывающие скобки на новых строках.
- Отступы в 4 пробела.

---

### Как выбрать стиль?
1. **LLVM/Google**: Хороши для современных проектов, где важна читаемость и единообразие.
2. **GNU**: Подходит для проектов, связанных с GNU/Linux.
3. **K&R**: Классический стиль, подходит для небольших проектов или учебных целей.
4. **Allman**: Хорош для проектов, где важна явная визуальная структура кода.
5. **Whitespace**: Может быть полезен для проектов, где важна максимальная читаемость.

Для автоматического форматирования кода можно использовать инструменты вроде `clang-format`, `astyle` или `uncrustify`, которые поддерживают большинство из этих стилей.
