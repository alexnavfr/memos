# Perl error ˆM during merge

## Prompt:
_Perl.XLdeploy.Ksh. Есть скрипт шел который запускает скрипт перл с переданными параметрами. Работающий скрипт после деливери начал выдавать ошибку `perlˆM not found". Предложи решение и возможные варианты почему ошибка._

Основная причина ошибки `perlˆM not found` скорее всего в том, что файл Perl-скрипта был сохранен в формате Windows (**CRLF** - `\r\n`), а выполняется в Unix-подобной системе, которая ожидает формат Unix (**LF** - `\n`). Символ `^M` - это отображение возврата каретки (Carriage Return, `\r`) в Unix.

## 🔍 Причины и решения проблемы

Вот наиболее вероятные причины и способы их устранения:

### Исправление формата файла
Самая частая причина - преобразование символов конца строки. Чтобы это исправить, можно использовать следующие команды в Unix-системе:

```bash
# Способ 1: Использование dos2unix
dos2unix your_perl_script.pl

# Способ 2: Использование sed
sed -i 's/\r$//' your_perl_script.pl

# Способ 3: Использование tr
tr -d '\r' < your_perl_script.pl > fixed_script.pl
mv fixed_script.pl your_perl_script.pl
```

### Проверка шебанг-строки
Убедитесь, что первая строка скрипта (шебанг) корректна и не содержит лишних символов:

```perl
#!/usr/bin/env perl
```

а не

```perl
#!/usr/bin/env perl^M
```

### Проверка переменных окружения
Убедитесь, что Perl установлен и доступен по тому же пути, что и в шебанг-строке. Можно проверить командой:

```bash
which perl
/usr/bin/env perl
```

## 💡 Рекомендации для XL Deploy

При работе с XL Deploy учитывайте следующее:

- **Артефакты**: Убедитесь, что Perl-скрипты доставляются как артефакты в правильном формате
- **Предварительная обработка**: Настройте шаг в процессе доставки для автоматического преобразования формата файлов
- **Системные требования**: Проверьте, что Perl установлен на целевых серверах и версия совместима

## ✅ Процесс диагностики и исправления

1. **Просмотр файла**: Выполните `cat -v your_script.pl | head -n 1` чтобы увидеть непечатаемые символы
2. **Преобразование**: Используйте `dos2unix` для конвертации файла
3. **Проверка прав**: Убедитесь, что у скрипта есть права на выполнение: `chmod +x your_script.pl`
4. **Тестирование**: Запустите скрипт вручную перед развертыванием через XL Deploy

Если проблема сохраняется после преобразования формата файла, проверьте полный путь к Perl в шебанг-строке и наличие всех необходимых Perl-модулей в системе.
