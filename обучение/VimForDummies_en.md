# Vim for Dummies

##

Vim для начинающих: выжить в первый день

Почему Vim?

· Мощный — один раз научился, пользуешься всю жизнь
· Быстрый — руки не уходят с клавиатуры на мышь
· Вездесущий — есть на любом Linux/Unix сервере

Философия Vim

Vim — модальный редактор:

· Normal mode — для навигации и команд (здесь проводим 80% времени)
· Insert mode — для ввода текста
· Visual mode — для выделения текста

Первый запуск

```bash
vim filename.txt  # открыть файл
```

Самое важное в первый день

1. Как выйти из Vim (запомните это!)

```bash
:q      # выйти (quit)
:q!     # выйти без сохранения (принудительно)
:wq     # сохранить и выйти (write + quit)
ZZ      # тоже сохранить и выйти (быстро!)
```

2. Движение по тексту (в Normal mode)

```bash
h       ← влево
j       ↓ вниз  
k       ↑ вверх
l       → вправо

w       следующее слово
b       предыдущее слово
0       начало строки
$       конец строки
gg      начало файла
G       конец файла
```

3. Редактирование текста
```bash
i       enter Insert mode before cursor
a       enter Insert mode after cursor
o       new line below and enter Insert mode
Esc     return to Normal mode (from any mode)
x       delete character under cursor
dd      delete line
yy      copy line
p       paste after cursor
u       undo
Ctrl+r  redo
``

Simple Workflow

1. Открываем файл: vim file.txt
2. Редактируем: нажимаем i, печатаем текст
3. Сохраняем: Esc → :w → Enter
4. Выходим: :q

Пример: создание и сохранение файла

```bash
vim diary.txt  # создаем файл
i              # переходим в режим ввода
Сегодня я освоил основы Vim!
Это не так сложно, как кажется.
Esc            # возвращаемся в нормальный режим
:wq            # сохраняем и выходим
```

Советы для первого дня

1. Не используйте стрелки — приучите себя к hjkl
2. Чаще нажимайте Esc — если сомневаетесь, возвращайтесь в Normal mode
3. Не пытайтесь выучить все сразу — осваивайте по 2-3 команды в день
4. Играйте — попробуйте vimtutor (введите в терминале)

Когда совсем трудно

· Застряли? Нажмите Esc несколько раз, затем :q!
· Забыли режим? Нажмите Esc — это "паника button"
· Нужна помощь? :help или F1

Напоследок

Первые 30 минут будут неудобными. Это нормально! Через час вы поймете базовые принципы, через день — будете редактировать тексты, через неделю — не захотите возвращаться к обычным редакторам.

Главное — не сдаваться после первых 15 минут! Vim окупит потраченное время многократно.
