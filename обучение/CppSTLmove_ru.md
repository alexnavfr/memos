# `std::move` в C++

`std::move` - это стандартная функция, представленная в C++11, которая реализует семантику перемещения, позволяющую эффективно передавать ресурсы между объектами.

## Основная идея

`std::move` выполняет:
1. **Преобразование типа** к rvalue-ссылке
2. **Подготовку объекта** к перемещению (не перемещает сам)
3. **Разрешение компилятору** использовать конструктор/оператор перемещения

## Синтаксис

```cpp
template <typename T>
constexpr std::remove_reference_t<T>&& move(T&& arg) noexcept;
```

## Как работает

```cpp
std::string str1 = "Hello";
std::string str2 = std::move(str1); // Перемещение содержимого

// Теперь:
// str1 - в валидном, но неопределённом состоянии (обычно пустая)
// str2 - содержит "Hello"
```

## Основные случаи применения

### 1. Перемещение объектов

```cpp
std::vector<std::string> v1 = {"a", "b", "c"};
std::vector<std::string> v2 = std::move(v1);

// v1 теперь пуст
// v2 содержит {"a", "b", "c"}
```

### 2. Возвращение из функций

```cpp
std::vector<int> create_big_vector() {
    std::vector<int> v(1000000);
    // ... заполнение вектора ...
    return std::move(v); // На самом деле, return v достаточно (NRVO)
}
```

### 3. Вставка в контейнеры

```cpp
std::vector<std::string> vec;
std::string str = "text";
vec.push_back(std::move(str)); // Избегаем копирования
```

### 4. Реализация классов с семантикой перемещения

```cpp
class MyClass {
    std::vector<int> data;
public:
    // Конструктор перемещения
    MyClass(MyClass&& other) noexcept 
        : data(std::move(other.data)) {}
    
    // Оператор перемещения
    MyClass& operator=(MyClass&& other) noexcept {
        data = std::move(other.data);
        return *this;
    }
};
```

## Важные особенности

1. **Не гарантирует перемещение** - просто делает возможным
2. **После перемещения** исходный объект в валидном, но неопределённом состоянии
3. **Для POD-типов** (int, float и т.д.) работает как копирование
4. **Не освобождает память** - только передаёт владение

## Что происходит после перемещения

Для стандартных контейнеров после перемещения:
- Исходный объект обычно становится пустым
- Размер становится 0
- Но гарантируется, что объект можно безопасно уничтожить или присвоить новое значение

## Ошибки использования

1. **Использование после перемещения** без переинициализации:
   ```cpp
   auto x = std::move(y);
   y.use(); // Опасность! Неопределённое поведение
   ```

2. **Избыточное перемещение**:
   ```cpp
   return std::move(local_var); // Часто мешает NRVO
   ```

3. **Перемещение константных объектов**:
   ```cpp
   const std::string s = "text";
   auto s2 = std::move(s); // Копирование, а не перемещение!
   ```

## Отличие от std::forward

- `std::move` - всегда преобразует в rvalue
- `std::forward` - условное преобразование (perfect forwarding)

## Пример эффективного использования

```cpp
void process(std::vector<int>&& data) {
    // Принимаем только rvalue
}

std::vector<int> prepare_data() {
    std::vector<int> data(1000);
    // ... заполнение ...
    return data; // Может использовать перемещение автоматически
}

int main() {
    std::vector<int> v = prepare_data();
    process(std::move(v)); // Явное перемещение
    
    // v теперь пуст, но валиден
    v = {1, 2, 3}; // Можно использовать снова
}
```

`std::move` - мощный инструмент для оптимизации производительности в C++, но требует аккуратного использования.

Перемещающие конструкторы и операторы присваивания в C++
1. Основная концепция
В C++11 появилась семантика перемещения, которая позволяет эффективно передавать ресурсы (например, динамическую память, файловые дескрипторы) из одного объекта в другой, избегая лишних копирований.

**Перемещающий конструктор (Move Constructor)**
Создает новый объект, "забирая" ресурсы у временного (rvalue) объекта.

**Перемещающий оператор присваивания (Move Assignment Operator)**
Передает ресурсы от одного существующего объекта другому.

2. Синтаксис
```cpp
class MyClass {
public:
    // Перемещающий конструктор
    MyClass(MyClass&& other) noexcept {
        // Забираем ресурсы у 'other'
        data_ = other.data_;
        other.data_ = nullptr; // Обнуляем, чтобы деструктор 'other' не освободил ресурс
    }

    // Перемещающий оператор присваивания
    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete[] data_;     // Освобождаем текущие ресурсы
            data_ = other.data_; // Забираем ресурсы у 'other'
            other.data_ = nullptr;
        }
        return *this;
    }

private:
    int* data_;
};
```
