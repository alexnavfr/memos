### **Основы Docker для macOS Catalina**

Docker — это платформа для разработки, доставки и запуска приложений в контейнерах. Контейнеры позволяют упаковать приложение со всеми его зависимостями в изолированную среду, что обеспечивает переносимость и согласованность работы на разных системах.

В этом разделе мы рассмотрим, как установить Docker на macOS Catalina и изучить основные команды для работы с контейнерами и образами. Последняя рабочая версия для macOS Catalina 4.15 [https://github.com/docker/for-mac/issues/6671]

---

### **1. Установка Docker на macOS Catalina**

1. **Скачивание Docker Desktop**:
   - Перейдите на официальный сайт Docker: [https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop).
   - Скачайте версию Docker Desktop для macOS.

2. **Установка Docker**:
   - Откройте скачанный файл `Docker.dmg`.
   - Перетащите значок Docker в папку `Applications`.

3. **Запуск Docker**:
   - Перейдите в `Applications` и запустите Docker.
   - Docker запросит разрешения на установку дополнительных компонентов. Подтвердите установку.
   - После запуска Docker появится значок в строке меню (вверху экрана).

4. **Проверка установки**:
   - Откройте терминал (через Spotlight или Finder).
   - Выполните команду:
     ```bash
     docker --version
     ```
     Вы должны увидеть версию Docker, например:
     ```
     Docker version 20.10.8, build 3967b7d
     ```

5. **Настройка Docker**:
   - Docker Desktop по умолчанию настроен для работы с macOS. Если у вас есть специфические требования (например, увеличение объема оперативной памяти для контейнеров), вы можете изменить настройки через Docker Desktop:
     - Нажмите на значок Docker в строке меню.
     - Выберите `Preferences`.
     - В разделе `Resources` можно настроить CPU, память и другие параметры.

### **2. Основные команды Docker**

После установки Docker можно приступать к работе с контейнерами и образами. Вот основные команды, которые нужно освоить:

#### **2.1. Работа с образами**
- **Поиск образов**:
  Чтобы найти образ в Docker Hub (официальный репозиторий Docker), используйте команду:
  ```bash
  docker search <имя_образа>
  ```
  Например:
  ```bash
  docker search ubuntu
  ```

- **Загрузка образа**:
  Чтобы скачать образ, используйте команду:
  ```bash
  docker pull <имя_образа>
  ```
  Например:
  ```bash
  docker pull ubuntu
  ```

- **Просмотр образов**:
  Чтобы увидеть список всех скачанных образов, выполните:
  ```bash
  docker images
  ```

- **Удаление образа**:
  Чтобы удалить образ, используйте:
  ```bash
  docker rmi <имя_образа>
  ```
  Например:
  ```bash
  docker rmi ubuntu
  ```

#### **2.2. Работа с контейнерами**
- **Запуск контейнера**:
  Чтобы запустить контейнер из образа, используйте команду:
  ```bash
  docker run <имя_образа>
  ```
  Например:
  ```bash
  docker run ubuntu
  ```
  Если вы хотите запустить контейнер в интерактивном режиме (с доступом к терминалу), добавьте флаги `-it`:
  ```bash
  docker run -it ubuntu /bin/bash
  ```

- **Просмотр запущенных контейнеров**:
  Чтобы увидеть список всех запущенных контейнеров, выполните:
  ```bash
  docker ps
  ```
  Чтобы увидеть все контейнеры (включая остановленные), добавьте флаг `-a`:
  ```bash
  docker ps -a
  ```

- **Остановка контейнера**:
  Чтобы остановить контейнер, используйте команду:
  ```bash
  docker stop <контейнер_id>
  ```
  Например:
  ```bash
  docker stop 1a2b3c4d
  ```

- **Удаление контейнера**:
  Чтобы удалить контейнер, используйте команду:
  ```bash
  docker rm <контейнер_id>
  ```
  Например:
  ```bash
  docker rm 1a2b3c4d
  ```

- **Просмотр логов контейнера**:
  Чтобы увидеть логи контейнера, выполните:
  ```bash
  docker logs <контейнер_id>
  ```

#### **2.3. Пример работы с контейнером**
1. Запустите контейнер с Ubuntu:
   ```bash
   docker run -it ubuntu /bin/bash
   ```
   Вы окажетесь внутри контейнера в командной строке Ubuntu.

2. Проверьте версию Ubuntu:
   ```bash
   cat /etc/os-release
   ```

3. Выйдите из контейнера, набрав `exit`.

4. Проверьте список контейнеров:
   ```bash
   docker ps -a
   ```

5. Удалите контейнер:
   ```bash
   docker rm <контейнер_id>
   ```

### **3. Полезные советы для macOS Catalina**
- **Использование Docker Desktop**:
  Docker Desktop предоставляет графический интерфейс для управления контейнерами и образами. Вы можете использовать его для мониторинга ресурсов, запуска и остановки контейнеров.

- **Проблемы с производительностью**:
  Если вы заметили, что Docker работает медленно, попробуйте увеличить объем оперативной памяти в настройках Docker Desktop.

- **Очистка ресурсов**:
  Чтобы освободить место на диске, удалите неиспользуемые образы и контейнеры:
  ```bash
  docker system prune
  ```

### **4. Практическое задание**
1. Установите Docker на macOS Catalina.
2. Скачайте образ Ubuntu:
   ```bash
   docker pull ubuntu
   ```
3. Запустите контейнер в интерактивном режиме:
   ```bash
   docker run -it ubuntu /bin/bash
   ```
4. Исследуйте контейнер (например, создайте файл, установите пакет).
5. Остановите и удалите контейнер.
