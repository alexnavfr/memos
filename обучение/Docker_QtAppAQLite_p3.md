# Part 3
Спасибо за уточнение! Теперь, когда мы знаем, что проект `TextReader` написан на C++ с использованием Qt5/6, CMake, SQLite и разработан на macOS Catalina, мы можем адаптировать `Dockerfile` для сборки и запуска этого проекта в контейнере. Давайте разберем, как это сделать.

---

### Контекст Dockerfile для C++ проекта с Qt, CMake и SQLite

1. **Базовый образ**:
   Поскольку проект использует C++ и Qt, нам нужно выбрать базовый образ, который включает в себя необходимые инструменты для сборки C++ и поддержку Qt. Для этого можно использовать официальный образ Ubuntu или Debian, так как они хорошо поддерживают Qt и CMake.

2. **Установка зависимостей**:
   В контейнере нужно установить:
   - Компилятор C++ (например, `g++` или `clang`).
   - CMake для сборки проекта.
   - Библиотеки Qt5/6.
   - SQLite для работы с базой данных.
   - Дополнительные инструменты, такие как `make` и `git`.

3. **Копирование и сборка проекта**:
   Проект будет скопирован в контейнер, а затем собран с помощью CMake.

4. **Запуск приложения**:
   После сборки приложение будет запущено внутри контейнера.

---

### Dockerfile для проекта TextReader

Вот пример `Dockerfile` для вашего проекта:

```Dockerfile
# Используем официальный образ Ubuntu 22.04 как базовый
FROM ubuntu:22.04

# Устанавливаем рабочую директорию
WORKDIR /app

# Устанавливаем необходимые зависимости
RUN apt-get update && apt-get install -y \
    build-essential \           # Компилятор C++ и базовые инструменты
    cmake \                     # CMake для сборки проекта
    qt6-base-dev \              # Библиотеки Qt6 (или qt5-base-dev для Qt5)
    libsqlite3-dev \            # Библиотека SQLite
    git \                       # Git для клонирования репозитория (если нужно)
    && rm -rf /var/lib/apt/lists/*  # Очистка кэша для уменьшения размера образа

# Копируем исходный код проекта в контейнер
COPY . .

# Создаем директорию для сборки
RUN mkdir build && cd build

# Собираем проект с помощью CMake
RUN cmake .. && make

# Команда для запуска приложения
CMD ["./TextReader"]
```

---

### Пояснение к Dockerfile

1. **Базовый образ**:
   ```Dockerfile
   FROM ubuntu:22.04
   ```
   Мы используем Ubuntu 22.04 как базовый образ, так как он хорошо поддерживает Qt и CMake.

2. **Установка зависимостей**:
   ```Dockerfile
   RUN apt-get update && apt-get install -y \
       build-essential \
       cmake \
       qt6-base-dev \
       libsqlite3-dev \
       git \
       && rm -rf /var/lib/apt/lists/*
   ```
   - `build-essential`: Устанавливает компилятор C++ и базовые инструменты для сборки.
   - `cmake`: Устанавливает CMake для управления сборкой проекта.
   - `qt6-base-dev`: Устанавливает библиотеки Qt6 (если используется Qt5, замените на `qt5-base-dev`).
   - `libsqlite3-dev`: Устанавливает библиотеку SQLite.
   - `git`: Устанавливает Git (если нужно клонировать репозиторий).
   - `rm -rf /var/lib/apt/lists/*`: Очищает кэш пакетов для уменьшения размера образа.

3. **Копирование исходного кода**:
   ```Dockerfile
   COPY . .
   ```
   Копирует все файлы из текущей директории (где находится `Dockerfile`) в рабочую директорию `/app` внутри контейнера.

4. **Сборка проекта**:
   ```Dockerfile
   RUN mkdir build && cd build
   RUN cmake .. && make
   ```
   - Создается директория `build` для сборки.
   - Запускается `cmake` для настройки проекта и `make` для компиляции.

5. **Запуск приложения**:
   ```Dockerfile
   CMD ["./TextReader"]
   ```
   После сборки приложение запускается с помощью команды `./TextReader`.

---

### Сборка и запуск контейнера

1. **Сборка образа**:
   Перейдите в директорию с `Dockerfile` и выполните команду:
   ```bash
   docker build -t textreader .
   ```
   Это создаст Docker-образ с именем `textreader`.

2. **Запуск контейнера**:
   Запустите контейнер с помощью команды:
   ```bash
   docker run -it --rm textreader
   ```
   - `-it`: Запускает контейнер в интерактивном режиме.
   - `--rm`: Удаляет контейнер после завершения работы.

---

### Дополнительные настройки

1. **Использование Qt5**:
   Если ваш проект использует Qt5, замените `qt6-base-dev` на `qt5-base-dev` в `Dockerfile`.

2. **Подключение к GUI**:
   Если ваше приложение использует графический интерфейс (GUI), вам нужно будет настроить Docker для работы с X11. Это требует дополнительных шагов, таких как установка переменной среды `DISPLAY` и монтирование сокета X11.

3. **Использование SQLite**:
   Если ваше приложение использует SQLite, убедитесь, что файл базы данных доступен внутри контейнера. Вы можете смонтировать его как том:
   ```bash
   docker run -it --rm -v /path/to/database.db:/app/database.db textreader
   ```
