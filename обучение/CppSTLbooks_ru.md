# Ресурсы для изучения контейнеров STL

## Книги на русском языке

1. **"Стандартная библиотека C++: справочное руководство"** - Николай Джосаттис
   *Подробное описание всех контейнеров STL с примерами использования и обсуждением особенностей.*

2. **"C++ и STL"** - Дмитрий Кнут
   *Фундаментальная книга, освещающая основы STL, включая контейнеры и алгоритмы.*

3. **"Эффективное использование STL"** - Скотт Мейерс (перевод)
   *Практические рекомендации по оптимальному использованию контейнеров STL.*

4. **"С++ на примерах"** - Павел Канакин
   *Содержит раздел с практическими примерами использования контейнеров STL.*

5. **"Язык программирования C++"** - Бьярне Страуструп (перевод)
   *Классическая книга от создателя языка, в которой есть главы, посвященные STL и контейнерам.*

## Книги на английском языке

1. **"The C++ Standard Library: A Tutorial and Reference, 2nd Edition"** - Nicolai M. Josuttis
   *Один из лучших ресурсов по STL, подробно рассматривающий все аспекты контейнеров.*

2. **"Effective STL: 50 Specific Ways to Improve Your Use of the Standard Template Library"** - Scott Meyers
   *Содержит глубокие рекомендации по эффективному использованию контейнеров STL.*

3. **"C++ Templates: The Complete Guide"** - David Vandevoorde, Nicolai M. Josuttis
   *Глубокое погружение в механику шаблонов, которые являются основой STL контейнеров.*

4. **"Professional C++"** - Marc Gregoire
   *Содержит современные практики использования STL в профессиональной разработке.*

5. **"C++ Primer, 5th Edition"** - Stanley B. Lippman, Josée Lajoie, Barbara E. Moo
   *Всесторонний обзор С++, включая подробные разделы о контейнерах STL.*

## Онлайн-ресурсы на русском

1. **Metanit.com** - https://metanit.com/cpp/tutorial/7.1.php
   *Хороший туториал по контейнерам STL с примерами.*

2. **PureCodeCpp.com** - https://purecodecpp.com/
   *Образовательный портал с курсами и статьями по С++ и STL.*

3. **Habrahabr** - Тематические статьи и обсуждения
   *Множество статей по использованию STL от русскоязычных разработчиков.*

4. **CyberForum.ru** - Форум программистов
   *Содержит множество практических примеров и решений проблем с STL.*

5. **ИНТУИТ.РУ** - https://intuit.ru/
   *Курсы по C++, включающие материалы по STL.*

## Онлайн-ресурсы на английском

1. **CPPReference** - https://en.cppreference.com/w/cpp/container
   *Полная документация по всем контейнерам STL с детальным описанием API и сложности операций.*

2. **C++ Core Guidelines** - https://isocpp.github.io/CppCoreGuidelines/
   *Рекомендации по эффективному использованию C++ от авторов языка, включая контейнеры STL.*

3. **CppCon Videos** - https://www.youtube.com/user/CppCon
   *Видеозаписи докладов с конференции CppCon, многие из которых посвящены оптимальному использованию STL.*

4. **Effective Modern C++** - Онлайн-статьи Скотта Мейерса
   *Серия статей о современных практиках C++, включая использование контейнеров STL.*

5. **Stack Overflow - C++ STL tag** - https://stackoverflow.com/questions/tagged/c%2b%2b-stl
   *Огромная коллекция вопросов и ответов, касающихся практического использования STL.*

## Интерактивные ресурсы

1. **Compiler Explorer (Godbolt)** - https://godbolt.org/
   *Онлайн-компилятор, позволяющий изучать ассемблерный код, сгенерированный для разных контейнеров STL.*

2. **Wandbox** - https://wandbox.org/
   *Онлайн-среда для экспериментов с разными версиями C++ и STL.*

3. **Quick Bench** - https://quick-bench.com/
   *Инструмент для быстрого сравнения производительности различных контейнеров STL.*

## Справочные материалы

1. **FluentCpp** - https://www.fluentcpp.com/
   *Блог с углубленными статьями о C++ и STL.*

2. **Модульные карты STL** - https://github.com/indy256/Full-stack-Developer-Interview-Questions-and-Answers/blob/master/algorithm/STL%20Algorithm%20Complexity.md
   *Таблицы со сложностью операций для всех контейнеров STL.*

3. **Тесты производительности STL** - https://github.com/gregory-pl/stl_containers_perftest
   *Репозиторий с тестами производительности различных операций контейнеров STL.*

Эти ресурсы помогут глубоко изучить контейнеры STL, от основ до продвинутого использования и оптимизации производительности.
