### **Многопоточное программирование в C++**

#### **Когда применяется:**
- Параллельные вычисления (обработка больших данных, симуляции).  
- Асинхронные операции (UI, сетевые запросы).  
- Распределённые системы (серверы, обработка запросов).  
- Ускорение работы за счёт использования нескольких ядер CPU.  

---  

#### **Плюсы:**
✔ Повышение производительности (использование всех ядер CPU).  
✔ Отзывчивость UI (долгие задачи выполняются в фоне).  
✔ Эффективное использование ресурсов (ожидание I/O не блокирует программу).  

#### **Минусы:**
❌ Сложность отладки (гонки данных, deadlocks).  
❌ Накладные расходы на создание потоков и синхронизацию.  
❌ Потенциальные проблемы с переносимостью.  

---  

### **Базовые примеры**

#### **1. Запуск потока с `std::thread`**
```cpp
#include <iostream>
#include <thread>

void task() {
    std::cout << "Hello from thread!\n";
}

int main() {
    std::thread t(task);
    t.join();  // Ожидание завершения потока
    return 0;
}
```  

#### **2. Синхронизация с `std::mutex`**
```cpp
#include <mutex>
#include <thread>

std::mutex mtx;
int counter = 0;

void increment() {
    mtx.lock();
    ++counter;
    mtx.unlock();
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    t1.join();
    t2.join();
    std::cout << counter;  // 2
    return 0;
}
```  

#### **3. Атомарные операции с `std::atomic`**
```cpp
#include <atomic>
#include <thread>

std::atomic<int> counter(0);

void increment() {
    ++counter;  // Безопасно без мьютекса
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    t1.join();
    t2.join();
    std::cout << counter;  // 2
    return 0;
}
```  

---  

### **Ошибки при использовании MT**
1. **Гонка данных** (Race Condition) – доступ к общим данным без синхронизации.  
2. **Взаимная блокировка** (Deadlock) – два потока ждут друг друга.  
3. **Голодание** (Starvation) – поток не получает ресурсы.  
4. **Избыточная синхронизация** – снижает производительность.  

---  

### **Когда что использовать:**
- **`std::mutex`** – если нужна явная блокировка (критические секции).  
- **`std::atomic`** – если операция атомарная (счётчики, флаги).  
- **`std::lock_guard` / `std::unique_lock`** – для автоматического управления мьютексом.  

**Пример `lock_guard`:**  
```cpp
std::mutex mtx;

void safe_increment() {
    std::lock_guard<std::mutex> lock(mtx);  // Автоматический unlock
    ++counter;
}
```  

---  

### **Вывод:**
Многопоточность в C++ требует аккуратной синхронизации. Основные инструменты:  
- `std::thread` – создание потоков.  
- `std::mutex` – защита данных.  
- `std::atomic` – атомарные операции.  
- `std::lock_guard` – безопасное управление мьютексом.  

⚠ **Важно:** избегать гонок и deadlock, использовать RAII для мьютексов.
