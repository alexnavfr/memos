# Разбор кода примера из собеседования SG

## 

```cpp
#include <stdio.h>
#include <string.h>

int main()
{
	char *hello = "bonjour";
	char *d = hello;
	const char *s = d;
	int i = 1;
	while(*d)
	{
		*d++ = *s;
		s += i;
		if( *s !='o')
		{
			i = -i;
		}
	};
	printf("%s\n", hello);
}
```

Разберём этот код построчно, выявим проблемы и предложим варианты исправления.

### Исходный код:
```c
int main()
{
    char *hello = "bonjour";  // Проблема 1: строковый литерал в не-const указателе
    char *d = hello;
    const char *s = d;
    int i = 1;
    while(*d)
    {
        *d++ = *s;           // Проблема 2: попытка изменить строковый литерал
        s += i;
        if( *s !='o')
        {
            i = -i;
        }
    };
    printf("%s\n", hello);
}
```

### Построчный анализ:

1. `char *hello = "bonjour";`
   - Проблема: строковый литерал "bonjour" помещается в не-const указатель `char*`. В C++ это ошибка, в C - устаревшая практика.
   - Исправление: `const char* hello = "bonjour";` или `char hello[] = "bonjour";`

2. `char *d = hello;`
   - Если `hello` указывает на строковый литерал, то `d` тоже будет указывать на него, что проблематично для модификации.

3. `const char *s = d;`
   - Создаётся const-указатель на те же данные.

4. `while(*d)`
   - Цикл продолжается, пока не встретит нулевой символ.

5. `*d++ = *s;`
   - Основная проблема: попытка записи в память строкового литерала (undefined behavior).
   - Также: копирование символа из `s` в `d` с последующим перемещением `d`.

6. `s += i;`
   - Перемещение указателя `s` на `i` позиций (вперёд или назад, так как `i` меняет знак).

7. `if( *s !='o') { i = -i; }`
   - Если текущий символ не 'o', меняем направление движения `s`.

8. `printf("%s\n", hello);`
   - Вывод результата (но код может упасть раньше из-за попытки модификации литерала).

### Основные проблемы:
1. Попытка модификации строкового литерала (undefined behavior).
2. Неочевидная логика работы с указателями (алгоритм прыгает по строке).
3. Возможный выход за границы строки при движении `s` назад.

### Варианты исправления:

**Вариант 1 (использование массива вместо литерала):**
```c
int main()
{
    char hello[] = "bonjour";  // Массив, а не указатель на литерал
    char *d = hello;
    const char *s = d;
    int i = 1;
    while(*d)
    {
        *d++ = *s;
        s += i;
        if( *s != 'o')
        {
            i = -i;
        }
    }
    printf("%s\n", hello);
    return 0;
}
```

**Вариант 2 (безопасная работа с литералом):**
```c
int main()
{
    const char *hello = "bonjour";  // Оригинал защищён от изменений
    char buffer[sizeof("bonjour")]; // Создаём буфер для изменений
    strcpy(buffer, hello);         // Копируем данные
    
    char *d = buffer;
    const char *s = d;
    int i = 1;
    while(*d)
    {
        *d++ = *s;
        s += i;
        if( *s != 'o')
        {
            i = -i;
        }
    }
    printf("%s\n", buffer);
    return 0;
}
```

**Вариант 3 (улучшенная логика с проверкой границ):**
```c
int main()
{
    char hello[] = "bonjour";
    char *d = hello;
    const char *s = hello;
    const char *end = hello + strlen(hello);
    int i = 1;
    
    while(*d && s >= hello && s < end)
    {
        *d++ = *s;
        s += i;
        if(*s != 'o')
        {
            i = -i;
        }
    }
    printf("%s\n", hello);
    return 0;
}
```

### Примечание:
Оригинальный код пытается сделать что-то вроде "прыгающего" копирования символов, но содержит серьёзные проблемы с памятью. Все предложенные исправления сначала решают проблему модификации литерала, а некоторые добавляют проверки границ для безопасности.
