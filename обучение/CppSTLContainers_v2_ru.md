# Контейнеры STL в C++

Стандартная библиотека шаблонов (STL) C++ предоставляет различные типы контейнеров для хранения и управления данными. Рассмотрим основные контейнеры, их характеристики и применение.

## Последовательные контейнеры

### vector
**Определение**: Динамический массив, который хранит элементы в непрерывной области памяти.

**Сложность операций**:
- Доступ к элементу: O(1)
- Вставка/удаление в конец: O(1) амортизированно
- Вставка/удаление в произвольное место: O(n)
- Поиск: O(n)

**Когда использовать**: Когда нужен быстрый доступ к элементам по индексу и частое добавление элементов в конец.

**Пример**:
```cpp
std::vector<int> numbers = {1, 2, 3, 4, 5};
numbers.push_back(6);  // Добавление в конец
int third = numbers[2];  // Быстрый доступ по индексу
```

### list
**Определение**: Двусвязный список, элементы которого могут быть размещены в разных областях памяти.

**Сложность операций**:
- Доступ к элементу: O(n)
- Вставка/удаление (при наличии итератора): O(1)
- Поиск: O(n)

**Когда использовать**: Когда требуются частые вставки и удаления в произвольных позициях.

**Пример**:
```cpp
std::list<int> numbers = {1, 2, 3, 4};
auto it = std::next(numbers.begin(), 2);  // Итератор на 3-й элемент
numbers.insert(it, 10);  // Вставка перед 3-м элементом
numbers.erase(it);  // Удаление 3-го элемента
```

### deque
**Определение**: Двухсторонняя очередь, обеспечивающая быстрое добавление/удаление элементов с обоих концов.

**Сложность операций**:
- Доступ к элементу: O(1)
- Вставка/удаление в начало/конец: O(1) амортизированно
- Вставка/удаление в произвольное место: O(n)
- Поиск: O(n)

**Когда использовать**: Когда нужно часто добавлять или удалять элементы как в начало, так и в конец коллекции.

**Пример**:
```cpp
std::deque<int> queue;
queue.push_front(1);  // Добавление в начало
queue.push_back(2);   // Добавление в конец
int first = queue.front();
int last = queue.back();
```

### array
**Определение**: Статический массив фиксированного размера.

**Сложность операций**:
- Доступ к элементу: O(1)
- Поиск: O(n)
- Изменение размера: невозможно

**Когда использовать**: Когда заранее известен размер коллекции и он не будет меняться.

**Пример**:
```cpp
std::array<int, 5> fixed = {1, 2, 3, 4, 5};
int third = fixed[2];  // Быстрый доступ по индексу
```

### forward_list
**Определение**: Односвязный список, поддерживающий только продвижение вперёд.

**Сложность операций**:
- Доступ к элементу: O(n)
- Вставка/удаление (при наличии итератора): O(1)
- Поиск: O(n)

**Когда использовать**: Когда нужен самый легковесный список и достаточно движения только вперёд.

**Пример**:
```cpp
std::forward_list<int> numbers = {1, 2, 3};
numbers.push_front(0);  // Добавление в начало
numbers.insert_after(numbers.begin(), 5);  // Вставка после первого элемента
```

## Ассоциативные контейнеры

### set
**Определение**: Отсортированная коллекция уникальных значений.

**Сложность операций**:
- Поиск/вставка/удаление: O(log n)

**Когда использовать**: Когда нужно быстро определять наличие элемента и требуется сортировка.

**Пример**:
```cpp
std::set<int> uniqueNumbers = {5, 2, 8, 2};  // {2, 5, 8}
bool exists = uniqueNumbers.find(5) != uniqueNumbers.end();  // Быстрый поиск
```

### map
**Определение**: Отсортированная коллекция пар ключ-значение с уникальными ключами.

**Сложность операций**:
- Поиск/вставка/удаление: O(log n)

**Когда использовать**: Когда нужна ассоциация между ключами и значениями, и требуется сортировка по ключу.

**Пример**:
```cpp
std::map<std::string, int> ages;
ages["Alice"] = 30;
ages["Bob"] = 25;
int aliceAge = ages["Alice"];  // Быстрый доступ по ключу
```

### multiset
**Определение**: Отсортированная коллекция значений, допускающая дубликаты.

**Сложность операций**:
- Поиск/вставка/удаление: O(log n)

**Когда использовать**: Когда нужна сортировка и разрешены повторяющиеся значения.

**Пример**:
```cpp
std::multiset<int> numbers = {1, 3, 3, 7};  // {1, 3, 3, 7}
auto range = numbers.equal_range(3);  // Диапазон всех элементов со значением 3
```

### multimap
**Определение**: Отсортированная коллекция пар ключ-значение, допускающая дубликаты ключей.

**Сложность операций**:
- Поиск/вставка/удаление: O(log n)

**Когда использовать**: Когда нужно связать несколько значений с одним ключом и сохранить сортировку.

**Пример**:
```cpp
std::multimap<std::string, std::string> phonebook;
phonebook.insert({"Alice", "123-456"});
phonebook.insert({"Alice", "789-012"});  // Два телефона для Alice
```

## Неупорядоченные ассоциативные контейнеры

### unordered_set
**Определение**: Коллекция уникальных значений, организованная с помощью хеш-таблицы.

**Сложность операций**:
- Поиск/вставка/удаление: O(1) в среднем, O(n) в худшем случае

**Когда использовать**: Когда нужно быстро проверять наличие элемента и порядок не важен.

**Пример**:
```cpp
std::unordered_set<std::string> words = {"hello", "world"};
bool contains = words.find("hello") != words.end();  // Быстрый поиск
```

### unordered_map
**Определение**: Коллекция пар ключ-значение с уникальными ключами, организованная через хеш-таблицу.

**Сложность операций**:
- Поиск/вставка/удаление: O(1) в среднем, O(n) в худшем случае

**Когда использовать**: Когда нужен быстрый доступ по ключу и порядок не важен.

**Пример**:
```cpp
std::unordered_map<std::string, int> scores;
scores["Alice"] = 95;
scores["Bob"] = 87;
```

### unordered_multiset
**Определение**: Неупорядоченная коллекция значений, допускающая дубликаты.

**Сложность операций**:
- Поиск/вставка/удаление: O(1) в среднем, O(n) в худшем случае

**Когда использовать**: Когда порядок не важен и нужна возможность хранить дубликаты.

**Пример**:
```cpp
std::unordered_multiset<int> numbers = {1, 2, 2, 3};
auto count = numbers.count(2);  // Количество элементов со значением 2
```

### unordered_multimap
**Определение**: Неупорядоченная коллекция пар ключ-значение, допускающая дубликаты ключей.

**Сложность операций**:
- Поиск/вставка/удаление: O(1) в среднем, O(n) в худшем случае

**Когда использовать**: Когда нужно связать несколько значений с одним ключом и порядок не важен.

**Пример**:
```cpp
std::unordered_multimap<std::string, std::string> tags;
tags.insert({"article", "c++"});
tags.insert({"article", "stl"});
```

## Контейнеры-адаптеры

### stack
**Определение**: Адаптер контейнера, реализующий стек (LIFO - последним пришел, первым ушел).

**Сложность операций**:
- Вставка/удаление: O(1)

**Когда использовать**: Когда нужна обработка элементов по принципу "последним пришел, первым ушел".

**Пример**:
```cpp
std::stack<int> stack;
stack.push(1);
stack.push(2);
int top = stack.top();  // Получение верхнего элемента (2)
stack.pop();  // Удаление верхнего элемента
```

### queue
**Определение**: Адаптер контейнера, реализующий очередь (FIFO - первым пришел, первым ушел).

**Сложность операций**:
- Вставка/удаление: O(1)

**Когда использовать**: Когда нужна обработка элементов по принципу "первым пришел, первым ушел".

**Пример**:
```cpp
std::queue<int> queue;
queue.push(1);
queue.push(2);
int front = queue.front();  // Получение первого элемента (1)
queue.pop();  // Удаление первого элемента
```

### priority_queue
**Определение**: Адаптер контейнера, реализующий приоритетную очередь, где элементы упорядочены по приоритету.

**Сложность операций**:
- Вставка: O(log n)
- Доступ к наивысшему приоритету: O(1)
- Удаление наивысшего приоритета: O(log n)

**Когда использовать**: Когда нужно всегда получать элемент с наивысшим приоритетом.

**Пример**:
```cpp
std::priority_queue<int> pq;
pq.push(3);
pq.push(5);
pq.push(1);
int highest = pq.top();  // Получение элемента с наивысшим приоритетом (5)
pq.pop();  // Удаление элемента с наивысшим приоритетом
```

## Выбор между контейнерами без потери производительности

1. **vector vs array**: 
   - Используйте `array`, если размер заранее известен и фиксирован
   - Используйте `vector`, если размер может меняться

2. **vector vs deque**:
   - Используйте `vector`, если вставки/удаления происходят преимущественно в конец
   - Используйте `deque`, если часто требуются операции в обоих концах

3. **list vs forward_list**:
   - Используйте `forward_list`, если нужен самый легковесный список и не требуется обратное перемещение
   - Используйте `list`, если нужны операции в обоих направлениях

4. **map/set vs unordered_map/unordered_set**:
   - Используйте упорядоченные версии (`map`, `set`), если важен порядок элементов
   - Используйте неупорядоченные версии, если порядок не важен и нужна максимальная скорость операций

5. **stack/queue адаптеры**:
   - По умолчанию они используют `deque`, но могут быть настроены на использование других контейнеров (например, `vector` или `list`) без потери производительности, если соблюдаются требования к операциям

Например, `std::stack` может быть создан на основе `std::vector` без потери производительности:
```cpp
std::stack<int, std::vector<int>> stack;
```

Это особенно эффективно, если коллекция не будет часто изменять размер, так как `vector` обеспечивает лучшую локальность кэша по сравнению с `deque`.
