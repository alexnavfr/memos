# Setup local network

Prompt:
_Существуют компьютеры: 1 windows, 2 ubuntu, 1 macos catalina и мобильные устройства на Android - телефон и планшет и устройств ios необходимо объединить все устройства в единую локальную сеть с возможностью обмена файлами. Учитываем что macos catalina почти всегда включен._

Для объединения всех устройств в единую локальную сеть с возможностью обмена файлами, можно использовать следующие шаги:

### 1. **Настройка локальной сети**
   - **Роутер**: Убедитесь, что все устройства подключены к одному роутеру через Wi-Fi или Ethernet. Это обеспечит их нахождение в одной локальной сети.
   - **IP-адреса**: Убедитесь, что все устройства получают IP-адреса в одной подсети (например, 192.168.1.x). Это можно проверить в настройках сети на каждом устройстве.

### 2. **Общий доступ к файлам**
   - **Windows**:
     - Включите сетевое обнаружение и общий доступ к файлам и принтерам в "Центре управления сетями и общим доступом".
     - Создайте общую папку, щелкните правой кнопкой мыши на папке, выберите "Свойства" → "Доступ" → "Общий доступ" и добавьте пользователей.
     - Убедитесь, что в настройках безопасности (вкладка "Безопасность") у пользователей есть права на чтение/запись.
   - **Ubuntu**:
     - Установите Samba для общего доступа к файлам:  
       ```bash
       sudo apt update
       sudo apt install samba
       ```
     - Настройте Samba, отредактировав файл `/etc/samba/smb.conf`. Добавьте в конец файла:
       ```ini
       [shared]
       path = /path/to/shared/folder
       browseable = yes
       writable = yes
       valid users = ваш_пользователь
       ```
     - Перезапустите Samba:
       ```bash
       sudo systemctl restart smbd
       ```
     - Добавьте пользователя Samba:
       ```bash
       sudo smbpasswd -a ваш_пользователь
       ```
   - **macOS Catalina**:
     - Откройте "Системные настройки" → "Общий доступ".
     - Включите "Общий доступ к файлам" и добавьте папки, которые хотите сделать доступными.
     - Настройте права доступа для пользователей.
     - Для доступа с Windows может потребоваться включить поддержку SMB в настройках общего доступа.
   - **Android**:
     - Используйте приложения для доступа к сетевым папкам, такие как **Solid Explorer** или **ES File Explorer**.
     - Подключитесь к общей папке через SMB (введите IP-адрес компьютера с общей папкой).
   - **iOS**:
     - Используйте приложения, такие как **Files** (встроенное) или **FileExplorer**, для подключения к сетевым папкам через SMB.

### 3. **Доступ к общим папкам**
   - **С Windows**:  
     - Откройте "Проводник" → "Сеть". Вы должны увидеть другие устройства в сети.
     - Для доступа к Ubuntu или macOS, введите `\\IP-адрес` в адресной строке проводника.
   - **С Ubuntu**:  
     - Откройте файловый менеджер (например, Nautilus) и выберите "Другие места". Введите `smb://IP-адрес` для доступа к общим папкам.
   - **С macOS**:  
     - Откройте Finder → "Переход" → "Подключиться к серверу" и введите `smb://IP-адрес`.
   - **С Android и iOS**:  
     - Используйте выбранное приложение для подключения к общей папке через SMB.

### 4. **Дополнительные рекомендации**
   - **Использование NAS**: Если у вас много устройств и данных, рассмотрите возможность использования NAS (сетевого хранилища) для централизованного хранения и доступа к файлам.
   - **Резервное копирование**: Настройте резервное копирование важных данных, чтобы избежать их потери.
   - **Безопасность**: Убедитесь, что общий доступ защищен паролями, и используйте шифрование при передаче данных, если это возможно.

### 5. **Проверка сети**
   - Убедитесь, что все устройства могут "видеть" друг друга в сети. Для этого можно использовать команду `ping` с IP-адресами устройств.
   - Проверьте доступ к общим папкам с каждого устройства.

Таким образом, вы сможете организовать единую локальную сеть с возможностью обмена файлами между всеми устройствами.
