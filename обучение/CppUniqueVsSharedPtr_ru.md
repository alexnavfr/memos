# unique_ptr vs shared_ptr

## Prompt
_Простым языком объясни разницу между unique_ptr и shared_ptr. Приведи примеры использования. И различия._

В C++ `unique_ptr` и `shared_ptr` — это "умные указатели", которые автоматически управляют памятью, чтобы избежать утечек. Вот их основные различия:  

### 🔹 **`unique_ptr` (уникальный указатель)**
- **Владеет объектом единолично** – его нельзя скопировать, только переместить.  
- **Быстрее** чем `shared_ptr`, так как не считает ссылки.  
- **Удаляет объект**, когда выходит из области видимости или при явном `reset()`.  

#### Пример:
```cpp
#include <memory>

int main() {
    std::unique_ptr<int> u_ptr(new int(42));  // создали unique_ptr
    // auto u_ptr2 = u_ptr;  // Ошибка! Нельзя копировать unique_ptr
    auto u_ptr2 = std::move(u_ptr);  // Можно переместить владение

    if (u_ptr) {
        // u_ptr больше не владеет объектом
    }
    // u_ptr2 автоматически удалит int при выходе из области видимости
}
```  

### 🔹 **`shared_ptr` (разделяемый указатель)**
- **Подсчитывает ссылки** – несколько `shared_ptr` могут владеть одним объектом.  
- **Удаляет объект**, когда счетчик ссылок становится нулевым.  
- **Медленнее** из-за подсчета ссылок.  

#### Пример:
```cpp
#include <memory>

int main() {
    std::shared_ptr<int> s_ptr1(new int(42));  // создали shared_ptr
    auto s_ptr2 = s_ptr1;  // Теперь оба указывают на один int

    std::weak_ptr<int> w_ptr = s_ptr1;  // weak_ptr не увеличивает счетчик

    if (!w_ptr.expired()) {  // проверяем, жив ли объект
        auto s_ptr3 = w_ptr.lock();  // создаем новый shared_ptr
    }
    // s_ptr1 и s_ptr2 удалят int, когда оба выйдут из области видимости
}
```  

### 🔥 **Основные различия**
| Характеристика       | `unique_ptr`                  | `shared_ptr`                  |  
|----------------------|-------------------------------|-------------------------------|  
| **Владение**         | Единоличное                   | Разделяемое (много владельцев)|  
| **Копирование**      | Запрещено (только перемещение)| Разрешено                     |  
| **Производительность**| Быстрее (нет счетчика)        | Медленнее (есть счетчик)      |  
| **Использование**    | Когда владелец один           | Когда владельцев несколько    |  

### 💡 **Когда что использовать?**
- **`unique_ptr`** – когда у объекта **один владелец** (например, ресурс в классе).  
- **`shared_ptr`** – когда объект **делится между несколькими частями программы** (например, кэш).  
- **`weak_ptr`** – чтобы избежать циклических зависимостей (например, в двусвязных списках).  

Если можно обойтись `unique_ptr`, лучше использовать его – он эффективнее. `shared_ptr` нужен только для разделяемого владения.
