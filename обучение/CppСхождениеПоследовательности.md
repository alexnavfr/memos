# Схождение последовательности

## Prompt:
_C++. Напиши метод ìnt computeJoinPoint(int s1,int s2) который принимает на вход стартовые точки двух последовательностей и возвращает точку схождения этих последовательностей. Последовательность считается где следующицй номер является этим номером плюс сумма его digits_

### **Решение задачи на C++**

**Условие задачи:**  
Написать метод `int computeJoinPoint(int s1, int s2)`, который принимает стартовые точки двух последовательностей и возвращает точку их схождения. Каждое следующее число в последовательности вычисляется как текущее число плюс сумма его цифр.

**Пример:**  
- Последовательность 1: 471 → 471 + (4 + 7 + 1) = 483 → 483 + (4 + 8 + 3) = 498 → ...  
- Последовательность 2: 480 → 480 + (4 + 8 + 0) = 492 → 492 + (4 + 9 + 2) = 507 → ...  
- Точка схождения: **519** (проверяется вручную).  

---

### **Алгоритм решения:**
1. **Вычисление следующего числа в последовательности:**  
   Для числа `n` следующее число = `n + сумма его цифр`.  
   Например:  
   - `471 → 471 + (4 + 7 + 1) = 483`.  

2. **Поиск точки схождения:**  
   - Двигаемся по обеим последовательностям шаг за шагом.  
   - Если одна последовательность обгоняет другую, переключаемся на более медленную.  
   - Когда числа совпадают — это искомая точка.  

---

### **Код на C++:**
```cpp
#include <iostream>

// Функция для вычисления суммы цифр числа
int sumOfDigits(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

// Функция для поиска точки схождения
int computeJoinPoint(int s1, int s2) {
    while (s1 != s2) {
        if (s1 < s2) {
            s1 += sumOfDigits(s1);
        } else {
            s2 += sumOfDigits(s2);
        }
    }
    return s1;  // или s2 (они равны)
}

int main() {
    // Пример использования
    std::cout << computeJoinPoint(471, 480) << std::endl;  // Выведет 519
    return 0;
}
```

---

### **Как это работает?**
1. **Для `s1 = 471`, `s2 = 480`:**  
   - Шаг 1: `471 < 480` → `s1 = 471 + (4+7+1) = 483`.  
   - Шаг 2: `483 < 480` → `s2 = 480 + (4+8+0) = 492`.  
   - Шаг 3: `483 < 492` → `s1 = 483 + (4+8+3) = 498`.  
   - Шаг 4: `498 < 492` → `s2 = 492 + (4+9+2) = 507`.  
   - Шаг 5: `498 < 507` → `s1 = 498 + (4+9+8) = 519`.  
   - Шаг 6: `519 > 507` → `s2 = 507 + (5+0+7) = 519`.  
   - Результат: **519** (точка схождения).  

2. **Оптимизация:**  
   - Если одна последовательность значительно длиннее, алгоритм автоматически переключается на более медленную.  

---

### **Почему это эффективно?**
- **Сложность:** `O(k)`, где `k` — количество шагов до схождения.  
- **Память:** `O(1)` (не используем доп. память).  

---


**Вывод:**  
Метод корректно находит точку схождения для любых валидных входных данных.
