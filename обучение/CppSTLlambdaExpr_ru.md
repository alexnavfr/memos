# Лямбда-выражения в С++ простым языком.

## Prompt:
_Кратко и точно расскажи о лямбда в С++. Приведи четкие примеры с подробным объяснением._

Лямбда-выражения в C++ — это анонимные функции, которые позволяют определять функциональность "на месте" без создания отдельной именованной функции. Они введены в C++11 и широко используются для упрощения кода, особенно при работе с алгоритмами STL, функциями обратного вызова и многопоточностью.

### Синтаксис лямбда-выражения
```cpp
[capture](parameters) mutable -> return_type { body }
```
- **`[capture]`**: Список захвата — определяет, какие внешние переменные доступны внутри лямбды и как они захватываются (по значению `=` или по ссылке `&`).
- **`(parameters)`**: Параметры функции, как у обычной функции.
- **`mutable`**: (Опционально) Позволяет изменять захваченные по значению переменные.
- **`-> return_type`**: (Опционально) Тип возвращаемого значения.
- **`{ body }`**: Тело функции.

### Основные особенности
1. **Захват переменных**:
   - `[=]`: Захватывает все внешние переменные по значению.
   - `[&]`: Захватывает все внешние переменные по ссылке.
   - `[x, &y]`: Захватывает `x` по значению, `y` по ссылке.
   - `[]`: Ничего не захватывает.
2. Лямбда может быть сохранена в переменную типа `std::function` или `auto`.
3. Используется в алгоритмах STL (например, `std::sort`, `std::for_each`) и асинхронном программировании.

### Примеры с объяснением

#### Пример 1: Простая лямбда
```cpp
#include <iostream>

int main() {
    // Лямбда без захвата, принимает два параметра и возвращает их сумму
    auto sum = [](int a, int b) { return a + b; };
    std::cout << sum(3, 4) << std::endl; // Вывод: 7
    return 0;
}
```
**Объяснение**: Лямбда `sum` принимает два числа и возвращает их сумму. Поскольку она не захватывает переменные, квадратные скобки пусты (`[]`). Тип возвращаемого значения определяется автоматически.

#### Пример 2: Захват переменных
```cpp
#include <iostream>

int main() {
    int x = 10;
    // Захват x по значению
    auto printX = [x]() { std::cout << "x = " << x << std::endl; };
    printX(); // Вывод: x = 10
    x = 20;   // Не влияет на лямбду, так как x захвачен по значению
    printX(); // Вывод: x = 10
    return 0;
}
```
**Объяснение**: Лямбда захватывает `x` по значению (`[x]`), создавая копию `x` внутри лямбды. Изменение `x` в `main` не влияет на значение внутри лямбды.

#### Пример 3: Захват по ссылке и mutable
```cpp
#include <iostream>

int main() {
    int x = 10;
    // Захват x по ссылке, изменение x внутри лямбды
    auto incrementX = [&x]() mutable { x++; std::cout << "Inside: " << x << std::endl; };
    incrementX(); // Вывод: Inside: 11
    std::cout << "Outside: " << x << std::endl; // Вывод: Outside: 11
    return 0;
}
```
**Объяснение**: Захват `&x` позволяет лямбде изменять оригинальную переменную `x`. Ключевое слово `mutable` не требуется здесь, так как изменение происходит через ссылку.

#### Пример 4: Использование с STL
```cpp
#include <vector>
#include <algorithm>
#include <iostream>

int main() {
    std::vector<int> vec = {5, 2, 9, 1, 5};
    // Сортировка с использованием лямбды
    std::sort(vec.begin(), vec.end(), [](int a, int b) { return a > b; });
    for (int x : vec) {
        std::cout << x << " "; // Вывод: 9 5 5 2 1
    }
    return 0;
}
```
**Объяснение**: Лямбда используется как компаратор для `std::sort`, определяя порядок сортировки (по убыванию). Лямбда не захватывает переменные, так как работает только с параметрами `a` и `b`.

#### Пример 5: Лямбда с явным возвращаемым типом
```cpp
#include <iostream>

int main() {
    auto divide = [](double a, double b) -> double {
        if (b == 0) return 0.0;
        return a / b;
    };
    std::cout << divide(10.0, 2.0) << std::endl; // Вывод: 5
    std::cout << divide(10.0, 0.0) << std::endl; // Вывод: 0
    return 0;
}
```
**Объяснение**: Лямбда явно указывает возвращаемый тип (`-> double`) для ясности. Это полезно, если логика сложная, и компилятор не может автоматически определить тип возврата.

### Полезные замечания
- Лямбды можно передавать в функции, хранить в `std::function` или использовать в многопоточности (например, с `std::async`).
- Захват по значению создаёт копию, что безопасно, но может быть затратно для больших объектов.
- Захват по ссылке требует осторожности, чтобы избежать доступа к "висячим" ссылкам (например, если объект уничтожен).

Лямбда-выражения делают код компактнее и выразительнее, особенно в сочетании с STL и современными возможностями C++.
