# Копирование больших объемов в облако

## Prompt:
_CLI. Mac OS Catalina. Google Disk. Предложи варианты решения задачи копирования 12 гигобайт маленькими файлами на Google Disk_

Задача копирования 12 ГБ, состоящих из множества маленьких файлов, на Google Диск — классическая головная боль для штатного клиента. Он начинает бесконечно "сканировать" изменения и потреблять ресурсы системы, особенно на macOS Catalina . Лучшее решение — использовать специализированные консольные инструменты. Вот несколько вариантов, от самого эффективного до альтернатив.

---

### 🏆 Вариант 1. Rclone (Рекомендуемый)

Rclone — это золотой стандарт для работы с облачными хранилищами. Его называют "rsync для облака". Он создан именно для таких задач и отлично справляется с большим количеством файлов, поддерживая многопоточность и докачку при обрывах связи .

**Почему он идеально подходит:** Эффективно работает с API Google, почти не нагружает систему и позволяет запустить задачу и забыть о ней.

#### Как это сделать:

1.  **Установка:**
    Откройте Терминал и введите команду для установки через Homebrew:
    ```bash
    brew install rclone
    ```
    > **Важно:** Если вы планируете монтировать Google Диск как сетевой диск, не используйте версию из Homebrew. В этом случае установите rclone по [официальной инструкции](https://rclone.org/install/). Для простого копирования версия Homebrew подходит идеально .

2.  **Настройка подключения к Google Диску:**
    Запустите мастер настройки и следуйте инструкциям:
    ```bash
    rclone config
    ```
    *   Выберите `n` (New remote), чтобы создать новое подключение.
    *   Придумайте имя, например, `gdrive`.
    *   Выберите тип хранилища: введите `drive`.
    *   В остальных пунктах (Client ID, Client Secret и т.д.) можно нажимать Enter, оставляя значения по умолчанию.
    *   На вопрос о разрешениях (`scope`) выберите `1` (полный доступ).
    *   На вопрос об автоматической авторизации в браузере ответьте `y`.
    *   Браузер откроется сам. Войдите в свой аккаунт Google и разрешите доступ rclone.
    *   После успешной авторизации подтвердите создание конфигурации (на всех вопросах нажимайте `y` или Enter) .

3.  **Запуск копирования:**
    Выполните команду для копирования папки:
    ```bash
    rclone copy /путь/к/вашей/папке gdrive:ИмяПапкиНаДиске --progress --transfers 16 --checkers 32
    ```
    *   **`--progress`** — показывает процесс копирования .
    *   **`--transfers 16`** — копирует 16 файлов одновременно. Это значительно ускорит процесс. Можно поставить число до 32 .
    *   **`--checkers 32`** — запускает 32 проверки файлов параллельно, ускоряя сравнение локальной и удаленной версий.

### ⚙️ Вариант 2. Gdrive CLI и надстройки

Существует несколько консольных клиентов `gdrive`. Основной и поддерживаемый сейчас — `gdrive` версии 3. Он хорошо работает, но **не поддерживает синхронизацию папок** (команды sync) из коробки . Для загрузки папок понадобятся дополнительные инструменты.

**Подход:**
1.  Установите `gdrive@3` через Homebrew: `brew install gdrive` .
2.  Настройте OAuth (интерактивно) .
3.  Для копирования папок используйте скрипт-обертку, например, **`gdrive-stash`**. Он позволяет загружать папки рекурсивно (с флагом `-r`) .

Этот путь более сложен, чем rclone, и менее гибок, поэтому он рекомендуется, только если rclone по каким-то причинам не подходит.

---

### 🖥️ Вариант 3. Платный GUI-клиент Insync

Если вы не любите работать с терминалом, есть коммерческое решение. Insync — это сторонний клиент для Google Диска, который был создан для решения проблем с производительностью. Он умеет синхронизировать папки так, как это должен делать официальный клиент, и бережно относится к системным ресурсам. Однако это платный продукт, и в последних версиях у него урезана поддержка командной строки .

Это хороший выбор, если вам нужен надежный графический клиент, а не бесплатный консольный инструмент.

### 💎 Итог

Для копирования 12 ГБ маленьких файлов на macOS Catalina я настоятельно рекомендую **Rclone**. Это самый надежный и быстрый способ. Установите его, настройте за 5 минут и запустите копирование, указав количество одновременных потоков (`--transfers`). Остальное программа сделает сама.

Если вы захотите автоматизировать этот процесс в будущем (например, по расписанию), Rclone также отлично для этого подходит .
