# Иерархия скриптов

## Prompt:
_Bash. есть бинарный файл exec1, который принимает на вход 3 параметра. Этот исполняемый файл запускается через скрипт bash script1 и параметры передаются как $1, $2... В тоже время script1 вызывается скриптом script2. После того как отработали все скрипты без ошибок должен быть вызван скрипт номер 3 script3 который выполнит завершающие действия. Создай пример скрипта который объеденит все эти действия вместе._

Вот пример скрипта, который объединяет все эти действия:

## script2.sh
```bash
#!/bin/bash

# Проверяем, что передано 3 параметра
if [ $# -ne 3 ]; then
    echo "Ошибка: Необходимо передать 3 параметра"
    echo "Использование: $0 <param1> <param2> <param3>"
    exit 1
fi

# Сохраняем параметры
param1="$1"
param2="$2"
param3="$3"

# Вызываем script1 с параметрами
echo "Запуск script1 с параметрами: $param1, $param2, $param3"
./script1.sh "$param1" "$param2" "$param3"

# Проверяем код возврата script1
if [ $? -eq 0 ]; then
    echo "script1 выполнен успешно"
    
    # Запускаем script3 для завершающих действий
    echo "Запуск завершающих действий..."
    ./script3.sh
else
    echo "Ошибка: script1 завершился с ошибкой"
    exit 1
fi

echo "Все скрипты выполнены успешно"
```

## script1.sh
```bash
#!/bin/bash

# Проверяем, что передано 3 параметра
if [ $# -ne 3 ]; then
    echo "Ошибка: script1 требует 3 параметра"
    exit 1
fi

# Выводим информацию о запуске
echo "Запуск exec1 с параметрами: $1, $2, $3"

# Запускаем бинарный файл exec1 с параметрами
./exec1 "$1" "$2" "$3"

# Проверяем код возврата exec1
if [ $? -ne 0 ]; then
    echo "Ошибка: exec1 завершился с ошибкой"
    exit 1
fi

echo "exec1 выполнен успешно"
exit 0
```

## Альтернативный вариант - единый скрипт:

Если хотите объединить всё в один файл:

## master_script.sh
```bash
#!/bin/bash

# Проверяем наличие бинарного файла
if [ ! -f "./exec1" ]; then
    echo "Ошибка: Файл exec1 не найден"
    exit 1
fi

# Проверяем параметры
if [ $# -ne 3 ]; then
    echo "Ошибка: Необходимо передать 3 параметра"
    echo "Использование: $0 <param1> <param2> <param3>"
    exit 1
fi

# Функция для завершающих действий
script3() {
    echo "Выполнение завершающих действий..."
    echo "$(date): Все задачи выполнены с параметрами: $1, $2, $3" >> execution.log
    echo "Завершающие действия выполнены"
}

# Основной процесс
echo "Запуск exec1 с параметрами: $1, $2, $3"
./exec1 "$1" "$2" "$3"

if [ $? -eq 0 ]; then
    echo "exec1 выполнен успешно"
    script3 "$1" "$2" "$3"
else
    echo "Ошибка: exec1 завершился с ошибкой"
    exit 1
fi

echo "Все действия завершены успешно"
```

Этот подход обеспечивает:
- Проверку параметров
- Обработку ошибок на каждом этапе
- Последовательное выполнение скриптов
- Завершающие действия только при успешном выполнении всех предыдущих шагов
