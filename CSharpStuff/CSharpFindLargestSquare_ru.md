# Найти наибольший квадрат состоящий из 1 в данной матрице

# Prompt:
_Написать метод `int FindLArgestSquare(int[,] matrix)` Метод должен найти наибольший квадрат состоящий из 1 в данной матрице_

---

Ваша задача — найти **наибольший квадрат из 1** в двумерной матрице. Это классическая динамическая задача, которую можно решить с помощью **динамического программирования (DP)**.  

### **Алгоритм решения:**
1. **Создаём DP-матрицу** такого же размера, как исходная.
2. **Заполняем её** по правилу:
   - Если `matrix[i,j] == 0`, то `dp[i,j] = 0` (квадрат не может быть здесь).
   - Если `matrix[i,j] == 1`, то `dp[i,j] = min(dp[i-1,j], dp[i,j-1], dp[i-1,j-1]) + 1`.
3. **Находим максимум** в `dp` — это и будет размер наибольшего квадрата.

### **Код на C#:**
```csharp
public int FindLargestSquare(int[,] matrix)
{
    if (matrix == null || matrix.Length == 0)
        return 0;

    int rows = matrix.GetLength(0);
    int cols = matrix.GetLength(1);
    int maxSize = 0;

    // Создаём DP-матрицу
    int[,] dp = new int[rows, cols];

    // Заполняем первую строку и первый столбец как есть
    for (int i = 0; i < rows; i++)
    {
        dp[i, 0] = matrix[i, 0];
        if (dp[i, 0] == 1)
            maxSize = 1;
    }

    for (int j = 0; j < cols; j++)
    {
        dp[0, j] = matrix[0, j];
        if (dp[0, j] == 1)
            maxSize = 1;
    }

    // Заполняем остальную часть DP-матрицы
    for (int i = 1; i < rows; i++)
    {
        for (int j = 1; j < cols; j++)
        {
            if (matrix[i, j] == 1)
            {
                dp[i, j] = Math.Min(
                    Math.Min(dp[i - 1, j], dp[i, j - 1]),
                    dp[i - 1, j - 1]
                ) + 1;

                if (dp[i, j] > maxSize)
                    maxSize = dp[i, j];
            }
            else
            {
                dp[i, j] = 0;
            }
        }
    }

    return maxSize * maxSize; // Площадь квадрата (сторона^2)
}
```

### **Пример работы:**
**Входная матрица:**
```
1 1 0 1
1 1 1 1
0 1 1 1
```
**DP-матрица:**
```
1 1 0 1
1 2 1 1
0 1 2 2
```
**Максимальный квадрат:** `2x2` (значение `2` в `dp`), значит, ответ `4` (площадь).

### **Оптимизация (если не нужно хранить всю DP-матрицу):**
Можно использовать **одномерный массив** для экономии памяти:
```csharp
public int FindLargestSquare(int[,] matrix)
{
    if (matrix == null || matrix.Length == 0)
        return 0;

    int rows = matrix.GetLength(0);
    int cols = matrix.GetLength(1);
    int maxSize = 0;

    int[] dp = new int[cols + 1];
    int prev = 0;

    for (int i = 1; i <= rows; i++)
    {
        for (int j = 1; j <= cols; j++)
        {
            int temp = dp[j];
            if (matrix[i - 1, j - 1] == 1)
            {
                dp[j] = Math.Min(Math.Min(dp[j], dp[j - 1]), prev) + 1;
                maxSize = Math.Max(maxSize, dp[j]);
            }
            else
            {
                dp[j] = 0;
            }
            prev = temp;
        }
    }

    return maxSize * maxSize;
}
```

### **Итог:**
- **Сложность:** O(n×m) — время и память (или O(m) с оптимизацией).
- **Возвращает площадь** наибольшего квадрата из `1`.

### **Что такое DP-матрица?**
**DP (Dynamic Programming) матрица** — это вспомогательная таблица, которая хранит промежуточные результаты для решения задачи динамическим программированием.  

В задаче о **максимальном квадрате из 1**:  
- `dp[i, j]` = сторона наибольшего квадрата из `1`, заканчивающегося в `(i, j)`.  
- Заполняется на основе соседей:  
  ```
  dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
  ```

---

### **Построчное объяснение второго решения (с экономией памяти)**
Вместо хранения всей `dp[,]` (O(n×m)), используем **одномерный массив `dp[]`** (O(m)), где `dp[j]` обновляется на ходу.  

#### **Код с комментариями:**
```csharp
public int FindLargestSquare(int[,] matrix)
{
    if (matrix == null || matrix.Length == 0)
        return 0;

    int rows = matrix.GetLength(0);
    int cols = matrix.GetLength(1);
    int maxSize = 0;

    int[] dp = new int[cols + 1];  // +1 для удобства (избегаем проверок j-1)
    int prev = 0;  // Хранит dp[i-1][j-1] из предыдущей итерации

    for (int i = 1; i <= rows; i++)
    {
        for (int j = 1; j <= cols; j++)
        {
            int temp = dp[j];  // Сохраняем dp[i-1][j] перед обновлением
            if (matrix[i - 1, j - 1] == 1)
            {
                // dp[j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                dp[j] = Math.Min(Math.Min(dp[j], dp[j - 1]), prev) + 1;
                maxSize = Math.Max(maxSize, dp[j]);
            }
            else
            {
                dp[j] = 0;  // Квадрат не может заканчиваться здесь
            }
            prev = temp;  // Для следующей итерации prev = старое dp[j] (dp[i-1][j-1])
        }
    }
    return maxSize * maxSize;  // Площадь квадрата
}
```

#### **Как работает:**
1. **Инициализация:**
   - `dp[cols + 1]` — одномерный массив, где `dp[j]` соответствует `dp[i][j]` в полной версии.  
   - `prev` хранит значение `dp[i-1][j-1]` (левый верхний элемент для текущей ячейки).

2. **Пробегаем по матрице:**
   - Для каждой ячейки `(i, j)` (в коде `i-1, j-1` из-за индексации с 1):
     - **Сохраняем `temp = dp[j]`** — это `dp[i-1][j]` (значение сверху до обновления).  
     - Если `matrix[i-1][j-1] == 1`:
       - `dp[j] = min(dp[j], dp[j-1], prev) + 1`  
         - `dp[j]` — значение сверху (`dp[i-1][j]`).  
         - `dp[j-1]` — значение слева (`dp[i][j-1]`).  
         - `prev` — значение по диагонали (`dp[i-1][j-1]`).  
     - Обновляем `maxSize` — максимальная сторона квадрата.  
     - **Обновляем `prev = temp`** — теперь это `dp[i-1][j-1]` для следующей ячейки.  

3. **Результат:**
   - `maxSize * maxSize` — площадь наибольшего квадрата.

---

### **Пример для понимания:**
**Исходная матрица:**
```
1 1 0 1
1 1 1 1
0 1 1 1
```
**Шаги для `i = 2`, `j = 2` (`matrix[1][1] = 1`):**
1. `prev = dp[2]` (изначально 0).  
2. `dp[2] = min(dp[2]=1, dp[1]=1, prev=0) + 1 = 1` → `dp = [0, 1, 1, 0, 0]`.  
3. `maxSize` обновляется до `1`.  
4. `prev` сохраняет старое `dp[2] = 1` для следующей ячейки.  

**Итоговая `dp` после всех итераций:** `[0, 1, 2, 2, 1]` → `maxSize = 2`.  

---

### **Почему это работает?**
- Мы заменяем двумерный массив на одномерный, потому что для вычисления `dp[i][j]` нужны только:  
  - `dp[i-1][j]` (значение в `dp[j]` до обновления).  
  - `dp[i][j-1]` (значение `dp[j-1]`).  
  - `dp[i-1][j-1]` (значение `prev`).  
- `prev` аккуратно сохраняет "прошлое" значение перед перезаписью.  

**Сложность:**  
- Время: O(n×m).  
- Память: O(m) (вместо O(n×m)).  

Это классическая оптимизация DP "сворачиванием" матрицы в массив. 🚀
