Реализация на C#
Вот пример реализации на C# с подробными комментариями:

Copy
using System;

class Program
{
    // Метод для вычисления корня n-ой степени из числа A
    static double NthRoot(double A, int n, double epsilon = 1e-10)
    {
        // Начальное приближение
        double x0 = A;
        double x1;

        do
        {
            // Вычисляем следующее приближение по методу Ньютона
            x1 = ((n - 1) * x0 + A / Math.Pow(x0, n - 1)) / n;

            // Проверяем, достигли ли мы нужной точности
            if (Math.Abs(x1 - x0) < epsilon)
                break;

            // Обновляем текущее приближение
            x0 = x1;

        } while (true);

        return x1;
    }

    static void Main()
    {
        double A = 27; // Число, из которого извлекаем корень
        int n = 3;     // Степень корня

        double result = NthRoot(A, n);
        Console.WriteLine($"The {n}rd root of {A} is {result}");
    }
}
Построчные пояснения:
Метод NthRoot:

Принимает три параметра: число A, из которого нужно извлечь корень, степень корня n и точность epsilon.
x0 - начальное приближение, которое мы устанавливаем равным A.
x1 - следующее приближение, которое будет вычисляться на каждой итерации.
Цикл do-while:

Используется для итеративного уточнения значения корня.
Внутри цикла вычисляется следующее приближение x1 по формуле метода Ньютона.
Проверяется условие достижения заданной точности epsilon. Если разница между текущим и предыдущим приближением меньше epsilon, цикл завершается.
Обновляется текущее приближение x0 значением x1.
Метод Main:

Задаются значения числа A и степени корня n.
Вызывается метод NthRoot для вычисления корня.
Результат выводится на консоль.
Этот код позволяет вычислить корень n-ой степени из числа A с заданной точностью, используя метод Ньютона.
