### **Оценка сложности алгоритмов: просто и понятно**

Сложность алгоритма показывает, как быстро растёт время его работы или потребление памяти при увеличении размера входных данных.  

---

## **1. Основные критерии оценки**  
### **1.1. Временная сложность (Time Complexity)**  
Определяет, как быстро растёт время выполнения алгоритма при увеличении входных данных (`n`).  

### **1.2. Пространственная сложность (Space Complexity)**
Показывает, сколько дополнительной памяти требует алгоритм в зависимости от `n`.  

---

## **2. Как быстро оценить сложность?**  
### **2.1. Определите ключевые операции**  
- В цикле? → Зависит от количества итераций.  
- Рекурсия? → Зависит от глубины вызовов.  
- Вложенные циклы? → Умножаем их сложности.  

### **2.2. Упростите до Big-O (O-нотация)**
- Отбрасываем константы (`O(2n) → O(n)`).  
- Оставляем самый быстрорастущий член (`O(n² + n) → O(n²)`).  

### **2.3. Основные варианты сложности**
| Сложность      | Пример                          | Описание                          |
|----------------|---------------------------------|-----------------------------------|
| **O(1)**       | Доступ к элементу массива       | Константное время                |
| **O(log n)**   | Бинарный поиск                  | Логарифмический рост             |
| **O(n)**       | Линейный поиск                  | Пропорционально `n`              |
| **O(n log n)** | Быстрая сортировка (quicksort)  | Лучшие алгоритмы сортировки      |
| **O(n²)**      | Два вложенных цикла             | Медленно при больших `n`         |
| **O(2ⁿ)**      | Рекурсивный перебор (Фибоначчи) | Очень медленно                   |

---

## **3. Чёткий план оценки сложности**  
### **Шаг 1. Найти самый вложенный код**  
- Если есть циклы, смотрим на их количество и условия.  
- Если рекурсия, считаем глубину вызовов.  

### **Шаг 2. Определить зависимость от `n`**
- Одиночный цикл → `O(n)`  
- Два вложенных цикла → `O(n²)`  
- Деление пополам (бинарный поиск) → `O(log n)`  

### **Шаг 3. Упростить выражение**
- `O(3n + 5) → O(n)`  
- `O(2n² + n log n) → O(n²)`  

### **Шаг 4. Учесть память (если нужно)**
- Храним массив размером `n` → `O(n)`  
- Используем только константные переменные → `O(1)`  

---

## **4. Примеры**  
### **Пример 1: Линейный поиск**  
```python
for x in array:  # O(n)
    if x == target:
        return True
```
**Итог:** `O(n)`  

### **Пример 2: Сортировка пузырьком**
```python
for i in range(n):          # O(n)
    for j in range(n - 1):  # O(n)
        if arr[j] > arr[j + 1]:
            swap(arr[j], arr[j + 1])
```
**Итог:** `O(n²)`  

### **Пример 3: Бинарный поиск**
```python
while left <= right:     # Каждый раз делим пополам → O(log n)
    mid = (left + right) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
```
**Итог:** `O(log n)`
