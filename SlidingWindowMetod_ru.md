# Метод Скользящего окна. (Sliding window)

## Prompt:
_Расскажи о методе "Скользящего окна". В чем заключается. Когда применяется. Приведи 2-3 классических примера применения с построчным подробным объяснением. Язык С#._

Метод **скользящего окна (sliding window)** — это техника оптимизации, которая используется для эффективной обработки подмассивов (или подстрок) фиксированной или переменной длины во входном массиве (или строке), без повторного прохода по одним и тем же элементам.

---

### 🔹 **Суть метода:**

Вместо того чтобы каждый раз заново вычислять результат для каждой новой подстроки (или подмассива), мы:

* начинаем с "окна" (подмассива или подстроки) определённого размера,
* двигаем границы окна вправо, **удаляя** элементы, выходящие за левую границу, и **добавляя** новые элементы, входящие с правой стороны.

---

### 🔹 **Когда применяется:**

* При поиске **максимума/минимума/суммы** в подмассиве фиксированной длины.
* Поиск **наибольшей подстроки**, удовлетворяющей какому-либо условию.
* Подсчёт уникальных символов/элементов в текущем окне.
* Алгоритмы работы с потоками данных.

---

## 🔸 Пример 1: Максимальная сумма подмассива фиксированной длины `k`

**Задача:** Дано массив целых чисел `nums` и число `k`. Найти максимальную сумму подмассива длины `k`.

### 📄 C# код:

```csharp
int MaxSumFixedWindow(int[] nums, int k)
{
    int windowSum = 0;
    int maxSum = 0;

    // Считаем сумму первых k элементов
    for (int i = 0; i < k; i++)
        windowSum += nums[i];

    maxSum = windowSum;

    // Двигаем окно вправо, начиная с позиции k
    for (int i = k; i < nums.Length; i++)
    {
        // Удаляем левый элемент, добавляем правый
        windowSum += nums[i] - nums[i - k];

        // Обновляем максимум
        if (windowSum > maxSum)
            maxSum = windowSum;
    }

    return maxSum;
}
```

### 🧠 Пояснение:

* Сначала считаем сумму первых `k` элементов.
* Затем, при каждом шаге:

  * убираем `nums[i - k]` (элемент, выходящий за левую границу окна),
  * прибавляем `nums[i]` (новый элемент справа),
  * обновляем максимум.

## 🔸 Пример 2: Наименьшая подстрока с суммой ≥ `target`

**Задача:** Дан массив положительных чисел `nums` и целое число `target`. Найти **минимальную длину** подмассива, сумма которого ≥ `target`.

### 📄 C# код:

```csharp
int MinSubArrayLen(int target, int[] nums)
{
    int left = 0;
    int sum = 0;
    int minLength = int.MaxValue;

    for (int right = 0; right < nums.Length; right++)
    {
        sum += nums[right];

        // Пока сумма окна >= target, пытаемся сжать окно
        while (sum >= target)
        {
            minLength = Math.Min(minLength, right - left + 1);
            sum -= nums[left];
            left++; // сдвигаем левую границу
        }
    }

    return minLength == int.MaxValue ? 0 : minLength;
}
```

### 🧠 Пояснение:

* У нас **переменное окно** от `left` до `right`.
* Расширяем правую границу, пока сумма < `target`.
* Как только сумма ≥ `target`, **пробуем уменьшить окно**, двигая левую границу.
* Постоянно обновляем минимальную длину окна.

## 🔸 Пример 3: Длина самой длинной подстроки без повторяющихся символов (в строке)

**Задача:** Дана строка `s`. Найти длину самой длинной подстроки без повторяющихся символов.

### 📄 C# код:

```csharp
int LengthOfLongestSubstring(string s)
{
    HashSet<char> set = new HashSet<char>();
    int left = 0, maxLen = 0;

    for (int right = 0; right < s.Length; right++)
    {
        // Пока символ повторяется, удаляем слева
        while (set.Contains(s[right]))
        {
            set.Remove(s[left]);
            left++;
        }

        set.Add(s[right]);
        maxLen = Math.Max(maxLen, right - left + 1);
    }

    return maxLen;
}
```

### 🧠 Пояснение:

* Множество `set` хранит текущие уникальные символы в окне.
* При повторе символа мы сдвигаем левую границу, удаляя символы, пока не устраним дубликат.
* В каждой итерации обновляем максимальную длину окна.
