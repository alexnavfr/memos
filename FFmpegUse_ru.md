
# Использование ffmpeg для изменения разрешения и размера видеофайлов.

## Prompt
_как с помощью ffmpeg изменить разрешение 4k видео файлов mp4 на разрешение 720p без потери качества и со значительным уменьшением размера файла. Предоставь способ для macos calalina и ubuntu 24.0._

Чтобы изменить разрешение 4K видео до 720p с помощью `ffmpeg`, сохраняя при этом хорошее качество и значительно уменьшая размер файла, можно использовать следующий подход. Вот команды для macOS Catalina и Ubuntu 24.04:

### Общие параметры
- **Кодек**: Используем H.264 (libx264) для хорошего баланса между качеством и размером файла.
- **Битрейт**: Устанавливаем целевой битрейт, чтобы контролировать качество и размер файла.
- **Масштабирование**: Используем фильтр масштабирования для изменения разрешения.
- **Аудио**: Копируем аудио без изменений, чтобы сохранить качество звука.

### Команда для macOS Catalina и Ubuntu 24.04
Команда будет одинаковой для обеих систем, так как `ffmpeg` работает одинаково на macOS и Ubuntu.

```bash
ffmpeg -i input.mp4 -vf "scale=-1:720" -c:v libx264 -preset slow -crf 23 -c:a aac -b:a 128k output.mp4
```

### Пояснение параметров
- `-i input.mp4`: Указывает входной файл.
- `-vf "scale=-1:720"`: Масштабирует видео до высоты 720 пикселей, сохраняя пропорции.
- `-c:v libx264`: Использует кодек H.264 для видео.
- `-preset slow`: Устанавливает предварительную настройку кодирования на "slow" для лучшего баланса между скоростью и качеством.
- `-crf 23`: Устанавливает постоянный коэффициент качества (Constant Rate Factor). Значение 23 обеспечивает хорошее качество при значительном уменьшении размера файла.
- `-c:a aac`: Использует кодек AAC для аудио.
- `-b:a 128k`: Устанавливает битрейт аудио на 128 кбит/с.
- `output.mp4`: Указывает выходной файл.

### Установка ffmpeg
Если `ffmpeg` не установлен, вот как его установить на macOS Catalina и Ubuntu 24.04:

#### macOS Catalina
1. Установите Homebrew, если он еще не установлен:
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```
2. Установите `ffmpeg` с помощью Homebrew:
   ```bash
   brew install ffmpeg
   ```

#### Ubuntu 24.04
1. Обновите список пакетов:
   ```bash
   sudo apt update
   ```
2. Установите `ffmpeg`:
   ```bash
   sudo apt install ffmpeg
   ```

### Дополнительные советы
- Если вы хотите еще больше уменьшить размер файла, можно увеличить значение CRF (например, до 28), но это может немного ухудшить качество видео.
- Для более быстрого кодирования можно использовать предварительную настройку `medium` или `fast`, но это может немного ухудшить качество.

Эти команды должны помочь вам изменить разрешение видео и уменьшить его размер без значительной потери качества.
